# 知识工作台 0.1.0-alpha.5

桌面版本 0.1.0-alpha.5，配套 Codex 插件模板 0.1.0-alpha.6。沿用预发布渠道；只以 Release 页面实际提供且通过校验的资产为准。

## 更新

- 可选山岚 V2 外观、紧凑分类和晨间／月下场景。标题快速定位仅包含当前范围的正式笔记，不把收集箱和待审稿当作笔记打开；支持方向键、Enter、Esc、Tab／Shift+Tab 焦点循环及关闭后焦点返回。
- Ctrl／Cmd+K 展开导航侧栏并聚焦搜索；改善小窗口布局，密度和场景不改写保存的主题。
- 材料搜索、类型筛选与“只看已选”组合使用；只读来源预览，对照草稿生成时冻结的来源和参考文字，折叠 YAML 元数据。
- 保存失败阻止导航并保留输入，加载或只读状态同步锁定 CodeMirror。完善安装、数据、材料审核和 Codex 工作流说明。
- 更新插件模板版本，区分本次构建与先前 alpha.5 模板；没有自动修改已安装插件或权限。

## 下载与升级

Windows 使用 `KnowledgeWorkbench-0.1.0-alpha.5-win-x64.exe`。Apple Silicon macOS 使用同版本 DMG 或 ZIP，将完整应用放到“应用程序”。平台资产分别附有校验值和构建来源信息，缺失的资产不视为可用。

正常保存并退出旧应用，备份 Markdown、附件和必要恢复资料后再升级。笔记继续保留原位置；安装器遇到正在使用的应用会停止，不强制结束编辑。没有自动更新。

默认入口保留原外观。桌面添加 `--shanlan-daily` 使用山岚并沿用原配置；`--shanlan-preview` 使用独立预览配置且不注册全局截图热键。浏览器在本机地址后添加 `/?visual=shanlan`。

插件 ZIP 是不含本机配置的模板，不包含桌面运行时。更新桌面后在设置中准备本地插件并核对绑定，只有用户明确操作才安装或启用。

## 验证与限制

本轮本地 Windows 格式、类型、97 项单元／服务测试、构建、V2 界面、材料审核、隔离 Electron 和真实 SDK MCP stdio 测试通过。Windows 安装包与 macOS 包还需通过对应工作流的成品验证；最终状态以版本对应 Actions、构建来源及校验文件为准。

全部自动验收使用合成资料，不读取真实笔记。真实外部模型、当前 Codex 内嵌面板视觉验收、macOS 人工体验、中文输入法组合、多设备同步不在本轮验收结论内。Paperdesk 配套检查中系统 Edge 的既有宿主模拟虚拟时钟场景未通过，同场景在 Playwright Chromium 通过；此差异不作为本软件的真实宿主验收。

Windows 包未签名，macOS 包未做 Developer ID 签名或 Apple 公证，不保证下载后的 Gatekeeper 放行。AI 输出保持待审草稿，人工保存不代表科学结论已验证；冻结引用只覆盖文字，图片仍依赖原附件。
