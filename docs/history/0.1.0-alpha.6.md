桌面 alpha.6，Codex 插件 alpha.7。预发布资产、SHA256 与构建来源以 Release 实际提供内容为准；不覆盖旧 tag。

- 每次进入收集模式明确选择学习任务。材料、选择、草稿、整理批次和删除/恢复按任务隔离；历史材料保持原路径。无任务的全局截图先选择，取消不采集屏幕。
