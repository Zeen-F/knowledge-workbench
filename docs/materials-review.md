# 材料阅读与审核体验

本轮把“找到材料 → 只读核对 → 对照草稿”的路径集中起来，不增加新的模型调用或共享入口。

## 收集箱

- 可以按标题、正文、材料路径、文献标题或摘录搜索，并筛选纸间、图片或手写想法。
- “只看已选”与搜索、类型可以组合使用。筛选不清空选择，也不改变已有批次顺序；卡片角标仍显示真实的选择顺序。
- 点击卡片预览区打开只读阅读窗口。纸间材料显示文献与页码；可查看原图与 Markdown 正文，再决定加入所选或打开材料笔记。
- 点击卡片标题仍直接打开笔记。预览中的正文链接只显示文字，防止意外离开编辑现场；需跟随链接或回查纸间原页时先打开材料笔记。
- 无匹配结果时可一键清除筛选。关闭预览、按 Escape 或点击遮罩均不更改正文。

## 草稿审核

- 顶部汇总该草稿关联的原始材料、批次参考笔记和待核对项数量。
- 原始材料可折叠，参考笔记默认收起。两者展示整理时固定快照中的正文，参考资料不会随当前笔记被修改而悄悄替换。
- 图片仍按原附件路径读取，界面不会声称这是独立冻结的图片副本。来源快照缺失会明确提示。
- “打开当前材料笔记”和“打开当前参考笔记”会先保存审核编辑；保存失败时留在审核页，保留输入，允许重试。
- 接受草稿、人工确认与 canonical 的规则保持不变。Obsidian Markdown 权威、纸间受管理正文的 API/hash/revision 保护，以及显式共享固定批次的 MCP 边界均未修改。

## 验证

- `npm run check`：格式、类型、97 项单元/服务测试与桌面网页/原生面板生产构建通过。
- 新增 6 项回归：组合筛选与来源搜索、不改变选择顺序、只使用关联的固定来源与参考快照、只读 Markdown 的链接和 HTML 安全性、编辑器反复锁定/解锁时保留正文与选区。
- `npm run test:materials-review`：合成浏览器回归覆盖筛选、选择顺序、预览打开/关闭/焦点恢复、不自动共享、参考快照、失败保存时阻止跳转及重试、加载当前笔记期间锁定编辑；已接入 Windows/macOS CI，并输出两张界面截图。
- 本次云环境已有 Chromium 启动权限限制，浏览器脚本未在本地执行，实际交互/视觉结果以远端 CI 为准。未验收真实桌面、中文输入法、Codex 宿主、真实模型或个人知识库；未打包或发布安装包。

所有夹具均为合成资料，临时库和测试服务在脚本结束时清理；不依赖或提交用户笔记、密钥、本机数据库。
