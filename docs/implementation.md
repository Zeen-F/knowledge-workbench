# 实施和验收记录

版本：0.1.0-alpha.1；记录日期：2026-10-10。定位为可运行的 Windows x64 首版预览，尚未完成全部真实资料验收。

## 已实现

- 六个模块、标准 Markdown 文件布局、SQLite/FTS5 索引、三个交换契约、GitHub 私有仓库和 Windows 自动检查/打包工作流。
- 软件内 CodeMirror 编辑器、源码切换、数学公式、表格/代码块/图片/双链、笔记树与标签页、查找替换、自动保存、跨标签页撤销、新建/移动/重命名、冲突草稿和历史恢复。
- 森林、暖砂、雾蓝、夜读四套皮肤；桌面窗口与 Codex 内页面共用偏好和本地服务。
- 快捷区域截图、粘贴/拖入/批量图片、手写想法、独立来源记录、图片内容去重。
- 固定输入批次、Responses/Chat Completions、逐项识读和汇总、失败恢复、取消、来源校验、可编辑审核稿、部分接受、明确重新确认过期修订基准。
- MCP 的打开工作台、状态、列批次、读取材料/图片、提交草稿；只读取主动共享范围，不提供正式接受工具。
- Paperdesk 交换包消费者、重复/不完整包处理、版本受控正文接口、离线草稿及页码回查。生产端提交单独保存在 Paperdesk 的 `2ca7bfa`。

## 仍需真实环境验收

1. 用户在设置中配置服务与模型，运行真实图片识读和知识整理；对公式、符号、条件和来源逐项人工核对。
2. 真实中文输入法候选与组合输入；两台不同缩放显示器的系统截图。当前只验证了中文字符插入和单屏实际截图。
3. Paperdesk 导出分支与其当前发布分支合并后，再做两个产品的选择操作联调；已完成接口验收不代表该功能已随纸间正式发布。
4. 在用户确认测试效果后选择现有 iCloud 库，检查云文件下载延迟、附件和单设备编辑。当前开发和验收均使用隔离合成库，未改写个人库。
5. 长时间学习工作流、安装/卸载向导与异常断电的系统级检查。包未签名，不提供自动更新。

源码、隔离资料、运行时和交付物分别管理：Git 只追踪源码与文档；本机缓存/测试在忽略目录；安装包在 `release/`；工作台运行配置在用户目录下的 `.knowledge-workbench/`。失败测试产生的已知临时目录已按明确路径清理。
