# 实施和验收记录

版本：0.1.0-alpha.2；记录日期：2026-10-10。定位为可运行的 Windows x64 首版预览，尚未完成全部真实资料验收。

## 已实现

- 六个模块、标准 Markdown 文件布局、SQLite/FTS5 索引、三个交换契约、GitHub 私有仓库和 Windows 自动检查/打包工作流。
- 软件内 CodeMirror 编辑器、源码切换、数学公式、表格/代码块/图片/双链、笔记树与标签页、查找替换、自动保存、跨标签页撤销、新建/移动/重命名、冲突草稿和历史恢复。
- 森林、暖砂、雾蓝、夜读四套皮肤；桌面窗口与 Codex 内页面共用偏好和本地服务。
- 快捷区域截图、粘贴/拖入/批量图片、手写想法、独立来源记录、图片内容去重。
- 固定输入批次、Responses/Chat Completions、逐项识读和汇总、失败恢复、取消、来源校验、可编辑审核稿、部分接受、明确重新确认过期修订基准。
- MCP 的打开工作台、状态、列批次、读取材料/图片、提交草稿；只读取主动共享范围，不提供正式接受工具。
- Paperdesk 交换包消费者、重复/不完整包处理、版本受控正文接口、离线草稿及页码回查。生产端 PR #21 与消费者在两个真实服务间完成联调；绑定核对同库路径，回查核对原 PDF 哈希。
