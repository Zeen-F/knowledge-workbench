# 已确认产品需求

需求依据：用户提供的《软件开发需求》讨论中可读取的用户要求，以及本次确认。旧助手长回复未能读取，不作为已确认设计依据。私人会话地址只保存在本机开发记录中。

## 核心目标

- 第一版 Windows 桌面应用，面向个人模拟 IC 学习。
- 本应用是主要写作和编辑入口，采用 Typora 式即时渲染，支持源码模式。
- Obsidian 承载普通 Markdown 和附件，可兼容打开；不承担主要编辑任务。
- 平时可以不用 AI，自由写作并积累截图；以后批量处理。
- 知识要保留原始想法、来源、适用条件、疑问和新旧结论的演变。
- 新软件独立于 Paperdesk；PDF 阅读、选区和批注继续在纸间完成。

## 首版确认项

1. 快捷键区域截图、粘贴图片、拖入文件、多图导入。
2. 主题知识卡和学习记录；继承现有模板的 note_type/domain/status/source 等字段。
3. AI 结果自动保存为草稿，人工核对后才进入正式笔记。审核与 canonical 状态提升分开。
4. 同时支持软件内 API 和在 Codex 对话中发起的 MCP 整理，统一返回草稿。
5. 搜索、标签、来源及相关笔记；暂不提供全库问答。
6. 可在新软件编辑现有 Markdown，兼容 YAML、双链和相对附件路径。
7. 开发在隔离知识库中，验收后连接现有 iCloud 知识库。单篇笔记按单设备编辑使用。
8. GitHub 使用 Zeen-F/knowledge-workbench 私有仓库，纳入版本管理、自动检查和打包。

9. 支持森林、暖砂、雾蓝、夜读四种界面皮肤，并保存偏好。
10. Codex 插件直接在当前对话内打开工作台页面，可继续编辑；独立桌面窗口保留。

## 不在此次范围

云同步服务、移动端、多人协作、全库问答、自动更新和公开发布。没有真实执行的模型、宿主或发布结果必须标为未验证。
