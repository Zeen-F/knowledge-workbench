# 导航侧栏与 Obsidian 子目录

桌面 alpha.4、插件模板 alpha.5 的开发分支加入以下能力。

- 点击编辑区左上角的侧栏图标收起/展开；当前标签和未保存文字保留。
- 拖动左侧导航与编辑区之间的边界调整宽度（200–420 像素，随窗口留出编辑空间）。双击恢复默认宽度；边界获得焦点后可用左右键、Home、End 调整。
- 支持本机浏览器存储时记住宽度和收起状态。禁用存储的 Codex 沙箱仍可操作，但布局不保证跨重开保存。
- 低高度窗口压缩侧栏间距，笔记列表单独滚动，保留设置按钮。

## 选择资料范围

选库对话框可以选择含 `.obsidian` 的根目录，也可以选择其下的资料目录。程序向上识别所属库，不创建 `.obsidian`，不迁移笔记。

| 选择位置                     | 浏览和搜索范围                 | 新建资料位置                                   |
| ---------------------------- | ------------------------------ | ---------------------------------------------- |
| `研究库/`                    | 默认“我的知识库”，可切换整个库 | `研究库/KnowledgeWorkbench/`                   |
| `研究库/KnowledgeWorkbench/` | 该目录内的笔记                 | 复用已有 Cards、Journal、Inbox、Drafts、Assets |
| `研究库/电源研究/`           | 电源研究目录                   | `电源研究/KnowledgeWorkbench/`                 |

索引、任务、恢复状态和设置按选定目录分别保存在库外。切回以前选定的目录可恢复其任务和设置；已有待审任务应在创建该任务时的目录范围内完成审核。共享 Markdown 和图片仍在原位置。

为保留短双链的原意，点击链接和移动预检会枚举所属库中的笔记路径，但不读取范围外的笔记正文。指向其他目录的链接提示打开整个库；不会误选当前范围内的同名笔记。移动只更新所选范围内的引用，需要跨目录同步更新时应打开整个库。配置、回收站目录和越界 junction 不可作为普通资料访问。

Paperdesk 仍与所属 Obsidian 库核对身份，已有交换包位于该库的配套 Paperdesk 目录；导入结果写入当前范围。普通文件 API 不能借此访问范围外的笔记。未重新验收真实 Paperdesk 成品或个人云盘。

## 验证

Windows 合成临时库：91 项单元/服务测试、格式、类型和构建通过。新增桌面检查覆盖 12 个场景，包括真实鼠标拖动、收起后保留输入、重新打开、两个子目录切换、错误目录保留原编辑器、同名链接和桌面科研预览。选库测试只替换操作系统文件对话框的返回值，其余 IPC、路径检查、服务重启及磁盘读写使用真实应用。

Python Playwright / Edge 覆盖 7 项侧栏检查，包含 900×640 布局、键盘与双击、夜读侧栏和存储不可用场景；截图已查看。完整 Electron 回归 16 项、可靠性浏览器 8 组、MCP 9 个工具与面板协议 21 项通过。面板协议测试不等同于 Codex 桌面宿主实测；无真实模型调用、无正式知识库测试。

首轮检查发现小窗口底部设置被挤出，已修正并复测。桌面新增链接接口最初未进入 IPC 白名单，交互检查发现后已补齐；同时补齐旧科研预览接口。一次测试在保存完成前刷新，被离开保护拦截，改为等待实际保存确认。保留全部检查断言。

Windows x64 NSIS alpha.4 更新包已生成；使用包内真实 EXE 和独立临时用户目录，重复通过全部 12 项新增桌面检查。当前使用中的已安装程序尚未替换，插件模板 alpha.5 未安装进 Codex 缓存。

复现命令：`npm.cmd run check`、`npm.cmd run test:sidebar-subfolder`、`npm.cmd run test:ui`、`npm.cmd run test:mcp`、`npm.cmd run test:panel`、`npm.cmd run test:reliability-ui`。通过 `KWB_TEST_EXE` 指定包内 EXE 可重复成品测试。新增桌面检查已加入 Windows CI 配置；该分支尚未推送，因此不宣称远端 CI 通过。
